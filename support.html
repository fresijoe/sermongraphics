Support

For help with Sermon Graphics, contact Joseph Fresi.

Email: fresijoe@gmail.com

When reporting a problem, include the sermon title, what you expected, what happened, and a screenshot if useful. Avoid sending confidential sermon material unless it is necessary to resolve the issue.

Common issues

  • If outputs appear as a collage, request regeneration as separate standalone images.
  • The scripture blank should be visibly darker and textless.
  • The 16:9 thumbnail should be a separate composition, not a crop of the 3:1 main graphic.
